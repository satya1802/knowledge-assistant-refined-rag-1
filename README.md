# Knowledge Assistant - Refined RAG

Knowledge Assistant - Refined RAG MVP Page 1 Knowledge Assistant Refined Enterprise RAG Chatbot - MVP Build Specification AI Provider Google Gemini only Primary Data Source Uploaded Knowledge Base Fallback Gemini general knowledge only when Knowledge Base has no relevant match Persistence Documents, users, chat history, messages and settings persist across reloads/restarts Reference Stack FastAPI + React/TypeScript + SQLite locally / PostgreSQL + pgvector production Core rule: Knowledge Base first. Gemini general-knowledge fallback second. Reloading the application must never erase chat history, uploaded documents, users, or saved application data.

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
ruff check .
ruff format .
```
